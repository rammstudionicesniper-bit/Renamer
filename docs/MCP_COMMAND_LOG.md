규칙은 [AGENTS.md](../AGENTS.md) 참고. **새 항목은 맨 아래에 추가**합니다.

## 기록 형식

```
### YYYY-MM-DD HH:MM (KST) — 받은 에이전트: Claude / Codex / AGY / Grok
- 명령 출처: GPT (MCP)
- 명령 내용: (원문 또는 요약)
- 수행한 작업: (무엇을 했는지)
- 결과/상태: (완료 / 진행 중 / 보류 — 사용자 확인 대기 등)
- 사용자 보고: (보고 여부·시각)
```
