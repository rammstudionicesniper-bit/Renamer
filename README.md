# 연번 리네이머 (SeqRenamer)

여러 파일의 **원본 이름은 유지**하면서, 윈도우가 자동으로 붙인 `(1) (2) (3)…`
중복 표기를 **제거**하고 그 자리에 `_01`, `_02`, `_03` 형식의 연속 번호를 붙여
일괄 리네임하는 윈도우 데스크톱 유틸리티입니다.

> ⭐ **이 툴의 핵심 = 윈도우식 `(숫자)`를 벗겨내고 `_숫자`로 바꾸는 것.**
> 단순히 뒤에 번호만 붙이는 게 아닙니다.

## 핵심 동작

원본 이름 끝의 윈도우식 `(숫자)`·`복사본` 표기를 **먼저 제거한 뒤**,
`{정리된이름}_{연번}.{확장자}` 로 바꿉니다.

| 입력 (윈도우가 만든 것) | 출력 (원하는 것) |
|---|---|
| `Amb_..._Hum.wav` | `Amb_..._Hum_01.wav` |
| `Amb_..._Hum (4).wav` | `Amb_..._Hum_02.wav` |
| `Amb_..._Hum (5).wav` | `Amb_..._Hum_03.wav` |
| `Amb_..._Hum (7).wav` | `Amb_..._Hum_04.wav` |

❌ 절대 나오면 안 되는 결과: `..._Hum(4)_01.wav` — `(4)`가 이름에 남으면 실패.

## 기능

- **드래그앤드롭** — 파일 여러 개 / 폴더 / 혼합을 창에 끌어다 놓기
- **하위 폴더 포함** 옵션 (기본 ON)
- **`(숫자)`·`복사본`·`Copy` 제거** (기본 ON) — ` (4)`, `(5)`, ` - 복사본`, ` - Copy (2)`,
  그리고 이미 붙어 있던 `_01` 연번까지 제거해 재처리 시 `_01_01` 방지
- **자연 정렬** — `(2)`가 `(10)`보다 앞에 오도록 (단순 문자열 정렬 아님)
- **변경 전 → 변경 후 미리보기** 표, 충돌 행은 빨간색
- **충돌 방지** — 대상 이름이 이미 있으면 건너뛰고 경고 (덮어쓰기 금지)
- **되돌리기(Undo) 1회**
- 옵션: 자릿수(2~4), 시작 번호, 정렬 순서(파일명순/수정일시순/드롭 순서),
  폴더별 독립 연번, 확장자 필터(`wav, mp3`)

## 실행 (개발/테스트)

```bash
pip install -r requirements.txt
python main.py
```

## 단일 exe 빌드 (집 윈도우 PC)

```bat
build.bat
```

또는 직접:

```bash
pip install -r requirements.txt pyinstaller
pyinstaller --onefile --windowed --name SeqRenamer main.py
REM → dist\SeqRenamer.exe (설치 불필요, 더블클릭 실행)
```

```
Renamer/
├─ main.py               실행 진입점
├─ seqrenamer/
│  ├─ core.py            리네임 핵심 로직 (GUI 비의존, 테스트 대상)
│  └─ gui.py             PySide6 GUI
├─ tests/
│  └─ test_core.py       핵심 로직 + 엣지 케이스 테스트 (pytest)

```

로직(`core.py`)과 화면(`gui.py`)을 분리해 두어, 빌드가 불가능한 환경에서도
핵심 규칙을 테스트로 검증할 수 있습니다.

## 테스트

```bash
pip install pytest
python -m pytest
```

명세서 §9 엣지 케이스를 모두 커버합니다:

- `(4) (5) (6) (7)` 등 **모든 숫자** 제거 (`(4)`만 아님)
- ` (10)`이 ` (2)`보다 뒤로 정렬 (자연 정렬)
- 한 이름에 `(2) (3)` 여러 개 붙은 경우 전부 제거
- ` - 복사본`, ` - Copy (2)` 제거
- 이름 **중간** 괄호는 보존 (끝 앵커 `$`)
- 이미 `_01` 붙은 파일 재처리 시 `_01_01` 방지
- 서로 다른 서브폴더의 같은 이름 → 파일명 기준 통합 연번(기본) / 폴더별 독립(옵션)
- 확장자 대소문자 보존 (`.WAV` → `.WAV`)
- 파일명 공백/한글/특수문자
- 대상 이름 이미 존재 → 건너뛰고 경고
- 그룹 내 이름 교환(swap)도 임시명 2단계 리네임으로 안전 처리

## 급할 때 임시 대체 (PowerShell)

툴 없이 당장 `(숫자)`만 지우려면 대상 폴더에서:

```powershell
# 미리보기 (실제 변경 안 함)
Get-ChildItem -Recurse -Filter *.wav | Rename-Item -NewName { $_.Name -replace '\(\d+\)', '' } -WhatIf
# 실제 실행 (-WhatIf 제거)
Get-ChildItem -Recurse -Filter *.wav | Rename-Item -NewName { $_.Name -replace '\(\d+\)', '' }
```

단, 이 방법은 `(숫자)`만 지우고 `_01` 연번은 붙이지 않습니다.
